# Support

TermSense support is community-driven through GitHub.

## Bug reports

Use the repository bug report form:

https://github.com/Anuppaul/termsense/issues/new/choose

A useful bug report includes:

- TermSense version;
- Linux distribution;
- Bash version;
- terminal emulator;
- minimal command/prefix and key sequence;
- expected vs actual behavior;
- sanitized diagnostics when relevant.

## Feature requests

Use the feature request form for new command intelligence, shell UX improvements, providers, adapters, or packaging ideas.

For large features, please discuss the behavior before writing a substantial implementation.

## Questions

If the question is about installation or current documented behavior, check these first:

- [README.md](README.md)
- [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- [CONTRIBUTING.md](CONTRIBUTING.md)

If documentation does not answer the question, open an issue with enough environment detail to reproduce the context.

## Security

Do not report vulnerabilities in a public support issue.

Follow [SECURITY.md](SECURITY.md).

## Scope

Support is best effort. TermSense is an open-source project and does not currently provide a commercial SLA.

Requests that depend on private environments may require a minimal sanitized reproduction before maintainers can investigate.
